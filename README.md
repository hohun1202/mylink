# 🔗 mylink

> **장호현의 자기소개 & 링크 모음 페이지**  
> Next.js 16과 Tailwind CSS를 활용한 깔끔하고 미니멀한 개인 프로필 / 링크트리 웹 애플리케이션입니다.

---

## ✨ 주요 특징 (Features)

- **🎨 미니멀 & 모던 UI**: 깔끔한 카드 디자인과 부드러운 블러(Backdrop-blur) 효과
- **🌓 다크 모드 지원**: 시스템 설정에 맞춘 라이트/다크 테마 지원
- **⚡ Next.js 16 App Router**: 최신 Next.js 및 React 19 기반의 빠른 성능
- **📱 모바일 최적화**: 모바일 환경에서도 최적화된 반응형 레이아웃

---

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)

---

## 🚀 시작하기 (Getting Started)

### 1. 패키지 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 페이지를 확인합니다.

### 3. 프로덕션 빌드

```bash
npm run build
npm run start
```
